# Webs de clientes · AIZAP

Una carpeta por cliente. Cada carpeta tiene su propio `CLAUDE.md` con las instrucciones de esa web.

| Carpeta | Cliente | Estado |
|---|---|---|
| [grupo-pid](grupo-pid/) | Grupo PID (PID Agua, Pultrusión Canarias, Piscinas Optimus) | En revisión, faltan datos de la empresa |

## Añadir un cliente nuevo
1. Crear una carpeta con el nombre del cliente en minúsculas y con guiones (`panaderia-lopez`).
2. Meter dentro la web y un `CLAUDE.md` con las reglas del cliente.
3. Añadir una fila a la tabla de arriba.

No subir contraseñas, claves de API ni datos personales de clientes.
